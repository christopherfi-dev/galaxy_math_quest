# Planet Algora: a one-page sheet for testing with your children

**For:** Marc. **From:** the big world thread. 22 November 2026.
Print it, or keep it open beside you. About 30 minutes for one child.

## Before you start

- **Open the page on the child's iPad, held sideways.** Tap **Ship**, then **Start again**, so the child begins at the story.
- **Say only this:** "This is a new planet. Play it how you like. Tell me what you are thinking."
- **Then say nothing.** Do not point. Do not read for them. If they ask what to do, say "What do you think?" once. After that, help, and write down that you did.
- **Sit where you can see the screen and their face.**

## Watch for these. Tick, and write the time.

| | What to watch | Tick | Time, and what they said |
|---|---|---|---|
| 1 | **The story (6 pages).** Do they read, tap through, or press "Read to me"? | | |
| 2 | **The first minute on the map.** Do they tap the picture to walk? Do they find the village without help? | | |
| 3 | **Typing.** Do they ever tap the box and type? Or only tap words? Which doing words do they try? | | |
| 4 | **Playing with things.** Do they push, dig, take, talk to things that are not people? Do they laugh? | | |
| 5 | **Elder Rivet's painted board** (the finished example). Do they look at it, or tap through? | | |
| 6 | **The first machine.** How many tests before they try a plate? Do they tap "Write it down"? | | |
| 7 | **A wrong plate.** What do they do next: test again, or guess again? | | |
| 8 | **The third and fourth machines.** Bored? Faster? Do they sigh? | | |
| 9 | **The pouch and the bridge.** Do they plan, or walk from machine to machine and hope? Do they go back to the elder for a fresh pouch? | | |
| 10 | **"Say what will come out before you pull."** Do they work it out, count on fingers, or guess? | | |
| 11 | **The Nudge button.** Do they find it? Does the nudge help, or annoy? | | |
| 12 | **The loose cog** that rolls out on a walk. Fun, or a bother? | | |
| 13 | **The Needs list and the Map.** Do they ever open them? When? | | |
| 14 | **Getting lost.** Where do they stand still, or walk in circles? | | |
| 15 | **Over the river** (if they get there): the three towns, the tags, the fleet. Do they see why a green lamp can still be wrong? | | |
| 16 | **Words.** Which words do they stop at or ask about? | | |
| 17 | **When do they want to stop?** And do they ask to play again? | | |

## Three questions for afterwards

1. **"What was the planet's problem? What were you trying to do?"**
   (Listen for the Gate, the burnt plates, the rules. If they say "get the cards", the story did not land.)
2. **"What was the hardest part? What did you do when you were stuck?"**
   (Listen for: tested more, wrote it down, asked for a nudge, guessed, gave up.)
3. **"If you could add one thing to this planet, what would it be?"**
