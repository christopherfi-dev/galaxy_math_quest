# How to run the GMQ quest review in Claude Code

1. **Unzip this package** into a new folder on your laptop, for example `GMQ-world`.
2. **Download the Drive folder.** In Google Drive, right-click **Galaxy Math Quest** and choose **Download**. Drive makes a zip and turns Docs into Word files and Sheets into Excel files.
3. **Remove the private files** from that download: Users Info, Galaxy Math Quest - Users, API information, and the Math Assessment Test folder if it holds results (`SOURCES_Index.md` §1).
4. **Download the six files outside the folder** (`SOURCES_Index.md` §2).
5. **Put everything in `drive/`,** in the package folder.
6. **Add your Grade 3 maths scope and sequence** to `drive/`, if you have it.
7. **Fill in `INFO_FROM_MARC.md`.** Items 1–3 matter most.
8. **Open Claude Code in the folder** and say:

   > Read CLAUDE.md, INFO_FROM_MARC.md and TASK_Quest_Review.md, then do the task.

Claude Code reads `CLAUDE.md` by itself whenever it starts in this folder.

**What you get back:** reviews for each area, redesigned places in the template format, test scripts for every number rule, and a two-page summary with the decisions only you can make. By default it stops after the reviews so you can approve the verdicts first (`INFO_FROM_MARC.md`, item 10).

## What's in this package

| Path | What it is |
