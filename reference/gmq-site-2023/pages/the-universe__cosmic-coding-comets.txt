role="main" tabindex="0">Cosmic Coding Comets
Level 1: Basics of Block-Based Programming
Task 1: Introduction to Scratch: Learn the basics of Scratch, understand the interface, sprites, costumes, sounds, and blocks.
Task 2: Make Your Sprite Move: Create a program that makes a sprite move around the screen.
Task 3: Create Your First Project: Design and implement a project that involves moving sprites and changing backgrounds.
Level 2: Loops and Control Flow
Sub-level 1: Introduction to Loops
Task 1.1: Understand 'forever' loops: Learn about 'forever' loops and how they function.
Task 1.2: Practice with 'forever' loops: Create a simple project where a sprite moves around the screen in a 'forever' loop.
Task 1.3: Understand 'repeat' loops: Learn about 'repeat' loops and their usage.
Task 1.4: Practice with 'repeat' loops: Create a simple project where a sprite repeats an action a specific number of times.
Sub-level 2: Conditional Statements
Task 2.1: Understand 'if' statements: Learn about 'if' statements and how they are used to make decisions in code.
Task 2.2: Practice with 'if' statements: Create a simple project where a sprite behaves differently based on a condition (e.g., it changes direction when it hits the edge of the screen).
Task 2.3: Understand 'if-else' statements: Learn about 'if-else' statements and how they are used to choose between two alternative code paths.
Task 2.4: Practice with 'if-else' statements: Create a simple project where a sprite behaves differently based on two alternative conditions (e.g., the sprite does one thing if a certain condition is true, and something else if that condition is false).
Sub-level 3: Combining Loops and Conditional Statements
Task 3.1: Review of loops and conditional statements: Reinforce understanding of how to use loops and conditional statements individually.
Task 3.2: Combine loops and conditional statements: Create a project where a sprite uses both loops and conditional statements to interact with its environment (e.g., the sprite moves in a loop and changes direction based on a condition).
Level 3: Debugging and Problem Solving
Task 1: Introduction to Debugging: Learn how to identify common mistakes in a block-based programming project.
Task 2: Debug a Project: Receive a project with a few intentional mistakes and debug it.
Task 3: Design and Implement Your Own Project: Create a project on your own from scratch and debug any problems that arise.
Level 4: Advanced Project
Task 1: Plan and Design: Plan and design a game that uses all the concepts learned so far.
Task 2: Implementation: Implement the game you have designed.
Task 3: Testing and Debugging: Playtest the game, debug any issues, and make necessary improvements.
Task 4: Showcase Your Project: Show your game to the class, receive feedback, and iterate on the project based on the feedback received.
Each of these tasks should be followed by specific learning materials and exercises that guide students through the process. The tasks can be adjusted according to the pace and requirements of the students.
