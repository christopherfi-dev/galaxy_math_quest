## What is built

- The station: 15 tasks, 5 ship parts, 4 real-life tasks with teacher codes.
- Voltara: nine places, values on every place, days, two goals, four endings.
- Galactic Trade in space, and 20 small worlds made from a kit of parts.
- Helps: reading cards, number pad, kind words, a "Here" row of words to tap, and the game remembers what the child was looking at.
- A server (PHP) with logins, saving, codes, a class view and an AI reply check. The AI is off and has never answered a child.

## How the work is done

- `docs/index.html` is a copy of the game for GitHub Pages (the school blocks addresses with "claude" in them). **Copy the game file there again after every change:** `cp prototypes/kis_station_sketch.html docs/index.html`.

- Bump the "Sketch version" label on every publish.
- After each piece: update the guide, add a line to `INFO_FROM_MARC.md`, rebuild `GMQ_Quest_Review_2026-11-16.zip`, commit, push.
