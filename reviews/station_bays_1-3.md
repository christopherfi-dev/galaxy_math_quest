# KIS Station, bays 1–3 — quest review

**Date:** 2026-11-16
**Area:** Engine Core (1-1, 1-2, 1-3), Navigation System (2-1, 2-2, 2-3), Shield Generator (3-1, 3-2, 3-3)
**Stage:** review and verdict only. Nothing is redesigned here.

**Summary.** Nine tasks were read in every version found: the student site, the Drive folder "Space Station Initial quests", the printed sheets and the Google Forms that checked answers. Every number was recomputed in code. Two tasks are sound as printed and can be kept (2-1 on its printed map, 2-2). Five need fixes, mostly because the versions disagree or the numbers go past the 10 × 10 tables (1-1, 1-2, 2-3, 3-2, 3-3). One is too long for a period and should be split (1-3). One has no single answer and needs redoing (3-1). The biggest surprises: the cargo task has exactly **one** answer when it asks for 6 items, and the live site asks for 7; the printed fuel map is correct and well built, with exactly one route that works; and the two shield sheets carry three different totals (60, 80, 85).

Every claim is marked **[Source]**, **[Proposal]**, **[Conflict]** or **[Assumption]**.

## 3. Engine Core

### 1-1 Alien Artifacts

**1. Sources**
- Site page 1-1 and Drive "1-1 INTRO": the same text. [Source]
- "Things to Prepare": "Counters - 9 Red, 8 Blue, 4 Green, 9 Yellow". [Source]
- Google Form "1-1 - Engine Core Counters": one question, one accepted answer, **9849**. Wrong answer message: "That is not the correct answer. The Engine core might explode! Please count again." Right answer message: "Great job! You have unlocked the first of three Engine Core parts." [Source]
- Planning doc and the Engine Core overview page call the task "Space Debris" and say "The **sum** of these numbers will be the code". [Source]
- **[Conflict]** Sum or sequence. The task page and the form use the four counts side by side (9849). The planning doc and overview page say the sum, which would be 30.
- **[Conflict]** Name. "Space Debris Count" (overview page), "Alien Artifacts" (task page), "Engine Core Counters" (form).
- A Loom intro video is linked. Not viewed.

**2. Skill.** Sorting and counting up to 9 of each colour, 30 objects in all. "Pre-Requisite - Order of Strands" lists "Basic counting, recognizing numbers (Quest 1)". In "tasks / strand order" Numbers Quest 1 is place value to 1,000, so plain counting has no level there. Nothing is above Grade 3. The counting itself is below Grade 3. [Source for the mapping; the judgement is mine]

**3. Time.** About 10 minutes [Assumption]. Well inside 40.

**4. Steps.** 5 steps: look, count, write totals, make the code, enter it. One answer of one 4-digit number. Inside the typing limit.

**5. Reading.** 192 words. 7 of 27 sentences are over 10 words. Longest (19 words): "Click here -----> Unlock the Engine Core: Enter the code to unlock the Engine Core and power our spaceship!" Hard words: "accurately", "evaluate", "generate" (all in the Performance Assessment lines, which read as teacher text). Typos on the page: "colos..", "Your counts helps get spaceship ready to fly!"

**6. Maths check** (`checks/1-1_check.py`)
- 9, 8, 4, 9 in the order red-blue-green-yellow gives 9849. Matches the form. Correct.
- Red and yellow are both 9. So 2 of the 24 possible colour orders give 9849. A student who swaps red and yellow still gets in. The code cannot catch that mistake.
- All counts are one digit. That matters: a count of 10 or more would make the code unclear (10, 8, 4, 9 reads as 10849).

**7. Checkpoints.** One checkpoint, kind **hands-on result**: the student counts real counters and types the code. [Proposal]

**8. Per-student numbers.** Today every bag is the same, so one shared code ends the task for the class (handoff §3, item 4).

*Rule [Proposal]:* each bag holds four **different** counts from 3 to 9. No two bags in a set share a code. No two bags hold the same four numbers in another order.

*Tested on 10,000 seeds, two options:*

| Option | Bags | Rule failures | Chance a classmate's code opens your lock | Counters needed, class of 24 [Assumption] |
|---|---|---|---|---|
| Today | 1 version | — | 100% | 720 |
| 1 | 4 versions, 6 students each | 0 | 22% | at most 678, at most 216 of one colour |
| 2 | 24 bags, one each | 0 | 0% | at most 604, at most 181 of one colour |

- 840 codes are possible under the rule, from 35 sets of four numbers.
- Marc's own bag does not pass the rule, because red equals yellow.
- **What to check that could prove this wrong:** the server must know which bag a student holds. Either the server prints the fill list and the teacher fills the bags to match, or the teacher types each bag's counts into the class copy. A bag that loses a counter breaks its code, so bags need a recount now and then. Both are Marc's call.

**9. Hands-on.** Group **B**, as in handoff §6. The counters are the learning: sorting and counting real objects.

**10. Verdict: fix.** The task is short, clear and correct. Fix three things: give students different bags, make the four counts different, and settle "sum" against "sequence" in the text.

- The Engine Core station is "the spacecraft's powerhouse, where all energy is generated". The Engine Core itself is "locked away".
- A box, or bag, of alien artifacts in four colours.
- The lock has a temper: "The Engine core might explode! Please count again." Opening it unlocks "the first of three Engine Core parts".
- A picture of new aliens "on a far-away planet", five kinds.
- A galaxy "with five kinds of stars", and the star types: giants, supergiants, dwarfs. The brown dwarf "should be mostly ORANGE".
- [Proposal] The three Engine Core parts could be three things a child can see being fitted as each task is finished.

**Navigation System**
- The refuelling map is already a small world: Start A, stops B, D, F, G, C, H, J, Z, K, W, P, L, S, T, five fuel refill stations and End. [Proposal] Each stop could be a place a child flies to, with the fuel gauge read out on arrival.
- A star map where "our Navigation System's key part is lost". A wrong landing gets "You're going to crash!!!!" or "There is nothing here!!!!". The right one: "You have found the Navigation System key part!!!!!"
- [Proposal] 2-2 fits a typed world unusually well. Each grid cell is a place. Typing "go to 3,1" moves there, and the place gives the next instruction. The decoy chain becomes a real wrong turn that ends at an empty patch of space.
- The cargo hold, with 11 named items to pick up and weigh: space food, life support, science equipment, a water reservoir, communications gear, spare parts, landing gear, energy cells, space suits, navigation systems, emergency rations.

**Shield Generator**
- The Shield Generator is "the protective heart of our spacecraft", guarding against "space debris, asteroids, and harmful cosmic rays".
- An asteroid field with "three ways through the rocks".
- The shield is a ring of five sections, each named for a ship part: Shield Generator, Power Module, Weapons System, Engine Core, Navigation System. Power tokens are laid on each.
- A shield with a temper too: "Your shield is going to explode!" and, when right, "Your shield is calibrated correctly!!"
- [Proposal] The shield ring could show its sections lighting up as power is placed.
